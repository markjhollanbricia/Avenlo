NOVA

A clean, responsive SaaS landing page template built with HTML5, CSS3, vanilla JavaScript, and inline SVG.

Getting Started

NOVA is a static front-end template and does not require Node.js, npm, a build tool, or a framework.

Option 1 — Open Directly

Open index.html in a modern web browser.

Option 2 — Local Development Server

For development, use a local server such as the VS Code Live Server extension. This provides a more realistic development environment.

Tip: Keep the folder structure intact when opening the template locally, especially the paths to css/style.css and js/script.js.

Brand & Content

The demo brand is NOVA. Replace it with your own company, startup, product, or agency name.

Search for the demo content in index.html and replace the headings, descriptions, statistics, names, companies, and other placeholder content with your own copy.

Logo Update the NOVA text in the navbar, dashboard preview, and footer.
Hero Update the main headline, description, and CTA labels.
About Replace the demo company description and statistics.
Testimonials Replace the fictional names, companies, roles, and quotes.

Pricing

Pricing cards are located in the Pricing section of index.html. Edit the plan names, prices, billing periods, feature lists, and CTA labels directly in the markup. 

<div class="pricing-card featured">
    <span class="pricing-badge">MOST POPULAR</span>
    <h3>Pro</h3>
    ...
</div>

Remove the featured class and the pricing-badge if you do not want a highlighted plan.

Features

Each feature uses the reusable .feature-card component. You can replace the heading, description, and inline SVG icon. 

<div class="feature-card">
    <div class="feature-icon" aria-hidden="true">
        ... SVG icon ...
    </div>

    <h3>Feature Title</h3>
    <p>Feature description.</p>
</div>

FAQ

The FAQ uses a lightweight accordion powered by js/script.js. Add another .faq-item to create more questions.

The current JavaScript keeps one FAQ item open at a time. Clicking the active question closes it.

Contact Form

The included contact form is a styled front-end form layout. It does not send or store submissions by itself.

Backend required: Connect the form to your preferred form service, API, server-side handler, or other backend before using it for production submissions.

Replace the demo email address in index.html with your real contact address.

Responsive Design

NOVA is designed around three layout ranges:

Desktop 1025px and above
Tablet 769px to 1024px
Mobile 768px and below

JavaScript

JavaScript is located in js/script.js and handles the interactive behavior of the template.

  • Responsive mobile navigation
  • aria-expanded state for the menu
  • Automatic mobile-menu closing after navigation
  • FAQ accordion behavior
  • Mobile menu icon state: menu and close icons

Demo Content

NOVA contains fictional demonstration content intended to show the structure and visual possibilities of the template.

  • Demo dashboard statistics
  • Demo user names and companies
  • Demo testimonials
  • Demo pricing values
  • Demo contact information
Replace demo content before using NOVA for a real client, company, or product website.
